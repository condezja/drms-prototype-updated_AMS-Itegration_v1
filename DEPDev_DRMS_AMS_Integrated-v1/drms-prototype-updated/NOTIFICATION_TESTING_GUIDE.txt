==============================================
COMMON ISSUES AND SOLUTIONS
==============================================

ISSUE: Badge not showing
SOLUTION: 
- Hard refresh (Ctrl + Shift + R)
- Check console for errors
- Verify localStorage is enabled

ISSUE: Notification doesn't navigate
SOLUTION:
- Check console for errors
- Verify document reference is correct
- Try clicking different parts of the notification

ISSUE: Duplicate notifications
SOLUTION:
- Should be prevented automatically
- Check console for "Duplicate notification prevented"
- If duplicates still appear, clear localStorage and test again

ISSUE: Status not persisting
SOLUTION:
- Verify saveDocuments() is being called
- Check console for "Saved X documents to localStorage"
- Try hard refresh

ISSUE: Badge shows wrong number
SOLUTION:
- Console log should show correct count
- Try clicking "Mark all read" then send new document
- Check if notifications are filtered by current user
